# CryptoAudit — Initial Prototype (Tkinter Desktop)

This folder contains the initial desktop prototype of
CryptoAudit, built using the Tkinter library.

## How to run

pip install -r ../requirements.txt
python ui_tkinter.py

## Notes
- This is the early draft of the artefact before the
  web interface was introduced.
- The core cryptographic engine is shared with the
  final product at ../cryptoaudit/backend/core.py
- For the final product, run main.py from the
  project root.
